1. Calculate and format

The right side of an assignment is evaluated before its result is assigned to the name on the left.

Python cell
quantity = 3
unit_price = 12.50
discount_rate = 0.10
delivery_fee = 5
total = quantity * unit_price * (1 - discount_rate) + delivery_fee
print(f"Total: {total:.2f} AED")
assert total == 38.75

4. Group values with a loop

Trace the dictionary after each order.

Python cell
orders = [("A", 12), ("B", 8), ("A", 15)]
totals = {}
for customer, amount in orders:
    totals[customer] = totals.get(customer, 0) + amount
    print(customer, amount, totals.copy())
assert totals == {"A": 27, "B": 8}
A 12 {'A': 12}
B 8 {'A': 12, 'B': 8}
A 15 {'A': 27, 'B': 8}

5. Check shared objects

Two names can refer to the same list. A shallow copy separates the outer list.

Python cell
a = [1, 2]
b = a
b.append(3)
print("a after editing b:", a)
c = a.copy()
c.append(4)
print("a:", a, "c:", c)
assert a == [1, 2, 3]
assert c == [1, 2, 3, 4]
a after editing b: [1, 2, 3]
a: [1, 2, 3] c: [1, 2, 3, 4]
