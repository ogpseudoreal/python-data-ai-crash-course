# Python → Data → AI

A practical crash course for a complete beginner. Created 5 September 2026.

**Start with [the course handbook](COURSE.md).**

Your complete plan is **200 focused hours**: a 160-hour Python/data/ML foundation plus a 40-hour AI application and career bridge. At your chosen **10–15 hours a week**, budget roughly **14–20 weeks** for the planned work. Allow 220–260 hours if checkpoints need more practice. The course builds on your Excel and basic algebra knowledge and addresses all three of your goals. It establishes independent project skills and career foundations; it does not guarantee job readiness or expert ML practice.

## First 30 minutes

1. Open the handbook, read the learning contract, and do Module 0.
2. Create `hello.py`, run it, change a value, and run it again.
3. Begin Module 1. Stop reading after each example and type it yourself.

Use external links only when assigned or when an explanation is not clicking. The handbook and labs are your main path. No paid certificate, AI API, or GPU is needed for the supplied labs. External courses retain their own access terms. The 40-hour bridge includes your own real-model integrations; those applications are assignments to build, not completed apps bundled here.

## Working folder

Open this entire folder in VS Code, not an individual notebook alone. After following the environment setup in Module 0, select your `.venv` interpreter and select the same environment as the notebook kernel. Run notebooks in numerical order. Each notebook is self-contained except that Notebook 4 loads the included `data/orders.csv`.

The hidden `.course-env` folder, if present in the working copy, was used to validate these materials. It is not included in the downloadable course ZIP. Create your own `.venv` to learn the setup process.
